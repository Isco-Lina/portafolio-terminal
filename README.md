# 💻 Portafolio Terminal

Portafolio profesional con diseño inspirado en terminal/CLI, construido con Astro, TypeScript y Bootstrap 5.

## 🚀 Características

- **Astro 5** - Framework moderno y rápido
- **TypeScript** - Tipado completo
- **Bootstrap 5** - Diseño responsive
- **Tema Terminal/CLI** - Estilo oscuro con acentos neón
- **Accesible** - HTML semántico

## 🛠️ Instalación

```bash
npm install
npm run dev
```

## 📝 Personalización

Edita los archivos en `src/data/`:

- **profile.ts** - Información personal
- **skills.ts** - Habilidades técnicas
- **projects.ts** - Proyectos
- **experience.ts** - Educación y experiencia
- **certifications.ts** - Certificaciones

## 🎨 Tema

Variables CSS personalizables en `src/styles/global.css`

## 🚀 Deploy

Compatible con Vercel, Netlify y GitHub Pages.
